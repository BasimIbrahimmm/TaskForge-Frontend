# TaskForge

> **Forge focus. Finish stronger.**

TaskForge is a modern, responsive productivity and task management dashboard developed as **Full Stack Project 1** during an internship.

The project focuses on building a clean and interactive web interface using fundamental frontend technologies, with an emphasis on responsive design, usability, accessibility, and JavaScript-based interactions.

---

## 📌 Project Overview

TaskForge provides a centralized workspace where users can view their productivity information, manage tasks, monitor projects, and keep track of upcoming activities.

The interface is designed with a modern blue-based visual theme and supports both **Light Mode** and **Dark Mode**.

The project was developed using frontend fundamentals without relying on frontend frameworks.

---

## 🎯 Project Objectives

The main objectives of TaskForge are:

- Build a responsive web application using HTML5, CSS3, and JavaScript.
- Use semantic HTML structure.
- Create a modern and user-friendly dashboard.
- Implement responsive layouts using CSS Grid and Flexbox.
- Add interactive functionality using Vanilla JavaScript.
- Provide Light Mode and Dark Mode.
- Follow a mobile-first responsive approach.
- Maintain accessibility and usability.
- Create a clean and professional user interface.

## 🎨 Design

TaskForge uses a modern productivity-dashboard design focused on simplicity, clarity, and usability.

### Light Mode

The light theme uses:

- Blue as the primary theme color
- Clean light backgrounds
- White dashboard surfaces
- Blue accents
- Subtle borders and shadows
- Clear visual hierarchy

### Dark Mode

The dark theme uses:

- Deep navy backgrounds
- Dark dashboard surfaces
- Blue primary accents
- High-contrast text
- Subtle blue highlights

The two themes are intentionally designed to provide different visual experiences while maintaining the TaskForge identity.

---

## 🔤 Typography

TaskForge uses **Poppins** as its primary font.

Poppins was selected to provide a modern, clean, and professional appearance throughout the dashboard.

The font is applied across the main interface, including:

- Headings

- Buttons

- Forms
